Introduction to HTML

Prerequisites: None

What you'll learn

By the end of this lesson, you should be able to:

  • Explain what HTML is.
  • Understand what HTML is used for.
  • Recognize an HTML element.
  • Create a simple HTML page.
  • Write basic HTML headings and paragraphs.

1. What is HTML?

When you visit a website, you see things like:

  • Headings
  • Paragraphs
  • Images
  • Buttons
  • Links
  • Lists

But how does the browser know what each piece of content is?

That's where HTML comes in.

HTML stands for HyperText Markup Language.

HTML is used to structure the content of a web page.

Think of building a house:

HTML = structure
CSS = appearance
JavaScript = behavior

For example, HTML can tell the browser:

"This is the main heading."

or

"This is a paragraph."

or

"This is a link."

2. Your first HTML

Here's a simple HTML example:

html
<h1>Hello, world!</h1>
<p>Welcome to CodeBloom.</p>

When the browser reads this, it understands:

  • <h1> → this is a heading
  • <p> → this is a paragraph

So the browser displays:

Rendered output

Hello, world!
Welcome to CodeBloom.

3. Understanding HTML elements

Look at this:

html
<p>Hello!</p>

This is an HTML element.

It has three main parts:

structure
<p>       Hello!       </p>
 ↑           ↑            ↑
Opening    Content      Closing
 tag                    tag

The opening tag tells the browser where the element starts.

The closing tag tells the browser where it ends.

Try this:

Change the text inside the paragraph.

html
<p>I am learning HTML.</p>

What happens?

Run the code and see for yourself.

Spot the bug

Here's some HTML with a mistake in it:

html
<p>I am learning HTML.

What's missing here that would cause problems? Think about it before revealing the answer.

The closing tag </p> is missing. Without it, the browser doesn't know where this paragraph is supposed to end - so it guesses, usually by treating everything after it as still part of the same paragraph until something forces a break. On a real page with more content below, this can quietly break your layout in ways that are confusing to track down, because the actual mistake is way earlier than where the page starts looking wrong.

4. Your first HTML page

An HTML document normally has a basic structure like this:

html
<!DOCTYPE html>

<html>
  <head>
    <title>My First Page</title>
  </head>

  <body>
    <h1>Hello, world!</h1>
    <p>I am learning HTML.</p>
  </body>
</html>

Don't worry if this looks like a lot.

Let's break it down.

<!DOCTYPE html>

This tells the browser that the document is HTML.

<html>

This is the root element that contains the page.

<head>

Contains information about the page that isn't normally displayed as the main page content.

<title>

Sets the title shown in the browser tab.

<body>

Contains the content that appears on the page.

This basic document structure is part of the standard beginner foundation for HTML.

🔗 You'll use this when...

This exact <!DOCTYPE html> / <html> / <head> / <body> skeleton is the starting point for every single page you'll ever build on CodeBloom - including your final project. You're not just learning a lesson example, you're learning the thing you'll type first, every time, from here on.

5. Headings

HTML gives you six levels of headings:

html
<h1>Main heading</h1>
<h2>Second-level heading</h2>
<h3>Third-level heading</h3>
<h4>Fourth-level heading</h4>
<h5>Fifth-level heading</h5>
<h6>Sixth-level heading</h6>

The most important heading is usually <h1>.

Think of headings like the structure of a book:

structure
<h1>My Website
    <h2>About Me
    <h2>My Projects
        <h3>Project One
        <h3>Project Two

6. Paragraphs

Use <p> for paragraphs.

html
<p>
  HTML is used to structure content on the web.
</p>

You can have multiple paragraphs:

html
<p>I am learning HTML.</p>

<p>HTML is the foundation of web development.</p>
