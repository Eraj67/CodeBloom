# Security Policy


CodeBloom is currently under development.


## Reporting a Vulnerability

If you discover a security vulnerability in CodeBloom:

- Do not report it through a public GitHub issue; report it privately using GitHub's private vulnerability reporting feature.
- Include a clear description of the issue and steps to reproduce it.
- Do not include passwords, API keys, or other real secrets in your report.

We appreciate responsible security reports that help keep CodeBloom safe.
