📌 Project Overview

Create a weather application that displays live weather information for any city using a public API. In this project, you'll learn how to fetch real-time data, handle API responses, display temperature and weather conditions, and build a responsive interface with JavaScript.

📋 Requirements

  • Search Weather by City
  • Display Temperature
  • Show Weather Condition and Icon
  • Display Humidity and Wind Speed
  • Fetch Data Using a Public API
  • Handle Invalid City Names
  • Responsive User Interface
